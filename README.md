# Mem0 Agentic CLI Memory

An interactive Command Line Interface (CLI) application powered by **Mem0** that enables an AI agent to remember user inputs, manage conversational history, and store memory persistently.

## 🚀 About the Project
This project is built as a foundational step toward understanding agentic workflows and memory integration in AI applications. It captures user inputs through the terminal and utilizes the Mem0 framework to maintain context and track saved interactions.

## 🛠️ Tech Stack & Sources
- **Python** (Core Programming Language)
- **Mem0ai** (Memory Management Framework for AI)
- **Git & GitHub** (Version Control and Source Code Hosting)
- **Visual Studio Code** (Development Environment)

## ⚙️ How to Setup and Run

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/Mem0-Agentic-CLI-Memory.git](https://github.com/your-username/Mem0-Agentic-CLI-Memory.git)
   cd Mem0-Agentic-CLI-Memory

2. **BASH:**
   python -m venv venv
   # On Windows (Git Bash):
   source venv/Scripts/activate

3. **Install Depecndecies:**
   pip install mem0ai

4. **Run Application**
   python main.py
